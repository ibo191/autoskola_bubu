# Brand ikony Autoškoly BuBu

Dodaná sada obsahuje 25 motívov v modrej a tyrkysovej verzii. Originálne PNG sú uložené v `src/assets/icons/blue` a `src/assets/icons/mint`. Pre webové rozhranie sú vytvorené zmenšené lossless WebP varianty 192 × 192 px v `public/icons/ui`.

Ikony sa používajú ako dekoratívne doplnenie textu, preto majú v HTML prázdny `alt`. Význam a ovládanie nesmú závisieť iba od ikony alebo farby.

| Názov súboru                                | Motív                         |
| ------------------------------------------- | ----------------------------- |
| `email`                                     | e-mail                        |
| `calendar`                                  | kalendár / termín             |
| `phone`                                     | telefón                       |
| `location`                                  | poloha / pobočka              |
| `smile`, `concern`                          | emócia / spätná väzba         |
| `download`                                  | stiahnutie                    |
| `graduation`                                | ukončenie kurzu / skúška      |
| `car`, `car-automatic`                      | auto / automatická prevodovka |
| `motorcycle-front`, `scooter`, `motorcycle` | moto skupiny                  |
| `classroom-outline`, `classroom-solid`      | teória / výučba               |
| `hands-wheel`                               | praktický výcvik              |
| `heart`, `safety-heart`                     | ľudský prístup / bezpečnosť   |
| `conversation`                              | komunikácia                   |
| `settings`                                  | nastavenie / proces           |
| `pencil`                                    | prihláška / vyplnenie         |
| `target`                                    | cieľ / postup                 |
| `thumbs-up`                                 | spokojnosť                    |
| `idea`                                      | tip / vysvetlenie             |
| `warning`                                   | upozornenie                   |

Aktuálne nasadenie používa ikony v interaktívnej päťkrokovej ceste, sekcii dôvodov a kartách pobočiek. Farebný variant sa vyberá podľa pozadia: modrá na svetlých plochách, tyrkysová na modrej ploche.
